How you present the problem changes the answer — CogLoadBench shows LLMs lose accuracy to formatting alone

A NeurIPS 2026 paper borrowing Cognitive Load Theory from human learning shows that how a task is presented — not how hard it is — measurably changes LLM accuracy. Gupta, Liu and Zou built CogLoadBench to vary five presentation factors while holding difficulty constant, and propose an Extraneous Load Score (ELS) that can flag a costly prompt before you deploy it. Thanksgiving made for a quiet launch day, so today's edition leans on papers: linear-attention stability, sequential model editing, two timescales of forgetting, and a 35B medical multimodal model.

Presentation is not cosmetic. CogLoadBench varies five presentation factors across three reasoning task families while holding difficulty constant. Higher extraneous load often reduces accuracy by adding competition or complicating the reasoning path — reframing some “reasoning failures” as presentation failures.

A metric, and a fix at inference time. The Extraneous Load Score (ELS), computed from activations at prompt time, estimates a model's extraneous load and generalizes across task types and load levels. Shifting representations toward lower-load directions at inference improves average performance without changing prompt content.
