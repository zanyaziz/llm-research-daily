Agents · Benchmarks · Safety

Computer-using agents get a real-world exam — OS-Omni benchmarks long-horizon workflows

Friday's papers put agents under the microscope: a benchmark that grades computer-using agents on full multi-step workflows instead of single clicks, evidence that coding agents out-reason video models at visual tasks, and a 7,660-run audit showing agent patches are mostly tests and docs — plus two safety papers showing how easily models can be made to misbehave.

Workflows, not clicks. OS-Omni — Friday's No. 1 paper on Hugging Face Daily Papers with 111 upvotes — tests generalist computer-using agents on long-horizon workflows across platforms, the kind of realistic, multi-step goals users actually ask for, rather than isolated GUI actions.

And a reality check on patches. A 7,660-trajectory audit of GitHub Copilot CLI runs finds agent patches are bigger than developers', but the extra edits are mostly tests (61%) and documentation (13%) — on code alone, agents' work is at least as necessary as developers'. Two safety papers round out the day: LLMs implanting backdoors into other models, and a relational-safety benchmark for supportive conversations.
