Model releases

Z.ai's GLM-5.4 loops its way to flagship status

Z.ai's first Loop Transformer runs 28 shared layers twice per forward pass, claiming 2–3-trillion-parameter-class intelligence at ~750B parameters — with no benchmarks published yet. Anthropic's Claude Ship moves agents from writing code to approving it, and the day's papers show models improving themselves at test time and recovering from corrupted training data.

A flagship built by looping. GLM-5.4 is Z.ai's new flagship, built by converting the GLM-5 base into a looped architecture (26-layer prelude, 28 looped layers, 24-layer coda; 1M-token context; vision for visual coding). It is live now only for GLM Coding Plan subscribers in ZCode and Z.ai Chat; API access and open weights are promised after safety work, with no date. Every capability number is vendor-reported and unverified — no benchmark table, model card, or weights existed at launch.

From writing code to approving it. Meanwhile Anthropic launched Claude Ship in beta for GitHub Team/Enterprise customers: Code Review plus two new agents (PR Steward and Claude Approvals) that carry a pull request through review, fixes, and an approval decision under a team policy file.
